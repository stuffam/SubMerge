SubMerge v1.1.5
==============

File and folder comparison inside Sublime Text, in the spirit of WinMerge.


RESTART SUBLIME TEXT FIRST
--------------------------

Quit completely and start again — closing the window is not enough.
Sublime does not always finish loading a newly installed package until
it restarts.


GETTING STARTED
---------------

Ctrl+click two tabs to select them, right-click either one, and choose
"SubMerge: Compare Selected Tabs". Two files in the sidebar work the
same way, and so do folders.

Or press Ctrl+Shift+P (Cmd+Shift+P on macOS) and type "submerge" —
every command is on the Command Palette.

Inside a comparison, F7 and Shift+F7 move between differences, and
Ctrl+Alt+Right/Left copy the difference under the cursor to the other
pane (Cmd+Alt on macOS).


THE FULL USER GUIDE
-------------------

Tools > SubMerge > User Guide  — covers three-way and folder comparison,
CSV table view, file metadata, and troubleshooting.

Settings live at Tools > SubMerge > Settings.
