SubMerge v1.1.3
===============

Five key bindings are switched off by default now. SubMerge no longer
claims any key combination globally — the shortcuts that remain on only
fire inside a comparison or folder result.

The ones now off (they start a comparison, so they cannot be limited to
one): Ctrl+Alt+D, Ctrl+Alt+Shift+D, Ctrl+Alt+M, Ctrl+Alt+O, Ctrl+Alt+I.
Cmd instead of Ctrl on macOS.

To restore any of them, open Tools > SubMerge > Key Bindings and
uncomment the ones you want. All of them are on the Command Palette too:
press Ctrl+Shift+P and type "submerge".

Full notes: https://github.com/stuffam/SubMerge/releases/tag/v1.1.3
